# Feature Parity Matrix

Status values: `VERIFIED`, `BLOCKED - EXTERNAL`.

`VERIFIED` means the feature exists end-to-end (UI, API, MongoDB persistence, authorization, validation, reload persistence, audit trail, notifications/email, report/export) and is covered by automated unit/domain/integration tests or verified end-to-end workflows.
