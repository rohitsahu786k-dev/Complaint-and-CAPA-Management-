# Feature Parity Matrix

Status values: `NOT STARTED`, `IN PROGRESS`, `IMPLEMENTED`, `VERIFIED`.

`VERIFIED` means the rule is covered by a passing automated test. `IMPLEMENTED` means the production path exists end to end on the server but is not yet covered by a test or not yet surfaced in the React UI. Phase 3 delivers the screens; Phase 4 delivers email, exports and cron.

Last updated at the end of Phase 2.
